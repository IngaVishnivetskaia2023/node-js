## Серверные и клиентские сокеты

#### Два типа по РОЛИ
```
Клиентский socket:  Я ПОДКЛЮЧАЮСЬ к кому-то     (connect)
Серверный socket:   Я ЖДУ пока ко мне подключатся (bind + listen + accept)
```

```
Клиентский socket:            Серверный socket:

  socket()                      socket()
  connect(ip, port) ──→         bind(port)
  write(data)                   listen()
  read(data)                    accept() → новый socket
  close()                       close()
```

#### Браузер — только клиентские сокеты
```
Браузер ВСЕГДА инициирует соединение. Никогда не ждёт входящих.

fetch('https://api.example.com/users')
    │
    ▼
  socket()                         ← создал socket
  connect(api.example.com, 443)    ← Я подключаюсь К серверу
  write("GET /users HTTP/1.1...")  ← отправил запрос
  read() → ответ                   ← получил ответ
  close()                          ← закрыл

Браузер НИКОГДА не делает:
  bind(port)   ← не привязывается к порту
  listen()     ← не слушает входящие
  accept()     ← не принимает соединения

Никто не может "подключиться к браузеру".
Браузер всегда КЛИЕНТ.
```

#### Node.js сервер — И серверные И клиентские сокеты
```
Node.js сервер выполняет ДВЕ роли:

  1. ПРИНИМАЕТ запросы от браузеров     → серверный socket
  2. САМ ПОДКЛЮЧАЕТСЯ к другим сервисам → клиентский socket
```

```
Браузер          Node.js Server            PostgreSQL       External API
───────          ──────────────            ──────────       ────────────

                 СЕРВЕРНЫЙ socket:
                 bind(:3000)
                 listen()
  connect ──→    accept() → fd=6
  GET /users     read(fd=6)
                 
                 КЛИЕНТСКИЙ socket:
                 connect(postgres:5432) ──→  принял
                 write("SELECT * FROM...")    
                 read() ← результат    ←──  отправил данные

                 КЛИЕНТСКИЙ socket:
                 connect(api.stripe.com) ──→  принял
                 write("GET /charges...")
                 read() ← результат     ←──  отправил данные

                 СЕРВЕРНЫЙ socket:
  ←── ответ      write(fd=6, response)
                 close(fd=6)
```

#### пример
```
import http from 'node:http';
import { Client } from 'pg';
import fetch from 'node-fetch';

const server = http.createServer(async (req, res) => {
  // req/res — через СЕРВЕРНЫЙ socket (клиент подключился к НАМ)

  // Подключаемся к PostgreSQL — КЛИЕНТСКИЙ socket
  const db = new Client({ host: 'localhost', port: 5432 });
  await db.connect();
  //       ^^^^^^^^^ socket() → connect(localhost:5432)
  //       Node.js тут КЛИЕНТ для PostgreSQL
  const users = await db.query('SELECT * FROM users');

  // Подключаемся к внешнему API — КЛИЕНТСКИЙ socket
  const payments = await fetch('https://api.stripe.com/charges');
  //                           ^^^^^^^^ socket() → connect(api.stripe.com:443)
  //                           Node.js тут КЛИЕНТ для Stripe

  // Отвечаем браузеру — через СЕРВЕРНЫЙ socket
  res.end(JSON.stringify({ users, payments }));
});

server.listen(3000);  // bind(:3000) + listen() — СЕРВЕРНЫЙ socket
```

```
В одном запросе Node.js использует ТРИ socket-а:

  fd=6:  серверный   (принял запрос от браузера)
  fd=7:  клиентский  (подключился к PostgreSQL)
  fd=8:  клиентский  (подключился к Stripe API)
```

#### BSD и POSIX
```
1983: University of California, Berkeley
      Разработали BSD Unix (Berkeley Software Distribution)
      Придумали Socket API:
        socket(), bind(), listen(), accept(), connect(),
        read(), write(), close()

Это был ПЕРВЫЙ стандартный способ сетевого программирования.

До этого: каждая ОС имела свой несовместимый API для сети.

POSIX (Portable Operating System Interface):
  Стандарт IEEE, описывает "как ОС должна выглядеть для программиста"
  Включил BSD socket API в стандарт POSIX.1

Результат:
  Linux    — поддерживает BSD sockets  ✅
  macOS    — поддерживает BSD sockets  ✅
  FreeBSD  — поддерживает BSD sockets  ✅
  Windows  — WinSock (совместимая копия) ✅

  Один и тот же код с socket() работает ВЕЗДЕ.
  Node.js (libuv) вызывает эти же функции на любой ОС.

Т.е. когда ты пишешь:
  http.createServer(...).listen(3000)
  
Node.js вызывает тот же socket API который придумали в 1983 году.
```
