## Node.js FS Module и Buffers

#### Зачем FS модуль
Node.js работает на сервере → имеет прямой доступ к файловой системе ОС (в отличие от браузера, где это запрещено из безопасности):
```
Browser JS:                          Node.js:
  ❌ Нет доступа к диску              ✅ Полный доступ к файловой системе
  ❌ Нет чтения /etc/passwd           ✅ Читай/пиши любые файлы
  ❌ Sandbox                           ✅ Системный уровень
```

```
Твой JS код: fs.readFile('/data/config.json')
       │
       ▼
Node.js C++ binding (src/node_file.cc)
       │
       ▼
libuv: uv_fs_read()
       │
       ▼
System call: read(fd, buffer, count)
       │
       ▼
Kernel: VFS → ext4/NTFS → disk driver
       │
       ▼
Hardware: SSD/HDD читает блоки данных
       │
       ▼
Байты возвращаются обратно по цепочке → Buffer в JS
```


### Что такое Buffer
#### Проблема, которую решает Buffer
Файл на диске — это последовательность байтов. Не текст, не JSON, не картинка — просто байты. Один байт = 8 бит = число от 0 до 255.
```
Файл "hello.txt" на диске (hex dump):
  68 65 6c 6c 6f 0a

Файл "photo.png" на диске (hex dump):
  89 50 4e 47 0d 0a 1a 0a 00 00 00 0d 49 48 44 52 ...

Файл "data.gz" на диске (hex dump):
  1f 8b 08 00 00 00 00 00 00 03 ...
```

JavaScript исторически имел только строки (Unicode текст). 
Строки не могут представить произвольные бинарные данные — например, байт 0x89 не является в��лидным символом в UTF-8.

`Buffer` — это массив байтов фиксированной длины, **живущий вне V8 heap (в C++ памяти)**:

```
V8 Heap (JavaScript объекты):        C++ Memory (raw bytes):
┌─────────────────────────┐          ┌──────────────────────────┐
│ const buf = Buffer(...)  │────────→│ 68 65 6c 6c 6f           │
│ { length: 5,            │          │ (реальные данные здесь)   │
│   [[BufferData]]: ptr } │          └──────────────────────────┘
└─────────────────────────┘
  JS объект — обёртка                  Сырые байты в памяти
```

#### Buffer vs String vs TypedArray — когда что

```
                Buffer              String              Uint8Array
              ─────────           ──────────           ────────────
Содержит:     raw bytes           Unicode text         raw bytes
Где живёт:    C++ memory          V8 heap              V8 heap
Мутабельный:  ДА                  НЕТ                  ДА
Fixed size:   ДА                  НЕТ (immutable)      ДА
Node.js only: ДА                  НЕТ (везде)          НЕТ (везде)
Когда:        файлы, сеть,        текст, JSON,         browser бинарные
              crypto, streams     шаблоны              данные (Canvas, WebGL)
```
