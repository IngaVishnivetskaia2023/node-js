## Event Loop deep dive

### Reactor Pattern
The Reactor Pattern is a high-level description of how Node.js works under the hood. Let's start with the big picture before diving into the details.

There are 3 primary components: **Event Demultiplexer, Event Loop, and Event Queue**.

The algorithm behind the Reactor Pattern:

1. The Event Demultiplexer receives a request for an I/O operation and delegates it to the appropriate hardware (steps 1–3 in the diagram below).
2. Once the I/O request is processed (for example, data from a file is ready to be read), the Event Demultiplexer adds the registered callback to the Event Queue (steps 4–5).
3. The Event Loop takes those callbacks and executes them sequentially until the Event Queue is empty (step 6).
4. If there are no events in the Event Queue, the Event Loop gives control back to the Event Demultiplexer.
5. If there are no pending I/O operations registered in the Event Demultiplexer, the application exits.
